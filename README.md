# 🛡️ SR CyberShield

**Malicious URL Risk Detector | Cybersecurity Project**

SR CyberShield is a Python-based cybersecurity application designed to analyze URLs and help users identify potentially suspicious or malicious links.

## ✨ Features

- **URL Risk Analysis** — analyzes URL characteristics to identify potential security risks.
- **Risk Indicators** — provides information to help users understand suspicious URL patterns.
- **User Authentication** — login system for accessing the application.
- **Scan History** — stores scan records locally for later review.
- **Privacy Awareness** — helps users assess a URL without automatically opening the submitted website.

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Regular Expressions
- URL Analysis

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ranjannsudhanshu/SR-CyberShield.git
cd SR-CyberShield
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows:**

```cmd
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

## 🔒 Security and Privacy

This tool is intended for cybersecurity awareness and preliminary URL risk analysis. Its results do not guarantee that a URL is safe or malicious.

Do not enter real passwords, private tokens, or other sensitive information into untrusted websites.
